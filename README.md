## 🏢 Dormitory Management System (Backend)

A backend system designed to support a dormitory rental platform, including room management, contract handling, and payment processing.

### 🔹 Overview
This project focuses on building a scalable backend architecture for a real-world rental system. The API supports multiple user roles and handles complex workflows such as contract lifecycle and payment verification.

### 🔹 My Responsibilities
- Designed backend architecture and RESTful APIs
- Modeled relational database schema using Prisma
- Implemented authentication and authorization (JWT)
- Developed payment processing and verification logic

### 🔹 Key Backend Features
- Role-based access control (Owner / Member)
- Dormitory and room management APIs
- Contract lifecycle management
- Payment workflow:
  - PromptPay QR code generation
  - Payment slip upload handling
- Secure API middleware and validation

### 🔹 Tech Stack
- Node.js + Express
- Prisma ORM
- PostgreSQL
- Supabase (storage integration)

### 🔹 Highlights
- Designed normalized relational database schema
- Built secure authentication system with JWT
- Implemented real-world payment workflow logic
- Structured backend using modular architecture (routes, controllers, services)
- Handled async operations and error management in API layer

- Designing scalable RESTful APIs
- Managing relational data and migrations with Prisma
- Implementing authentication and role-based authorization
- Structuring backend projects for maintainability
